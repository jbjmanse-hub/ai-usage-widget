# AI 사용량 위젯 (AI Usage Widget)

[English](README.md) | **한국어**

ChatGPT, Claude, Cursor, Perplexity, Grok 같은 **구독형 AI 서비스의 남은 사용량**을 Windows 바탕화면 구석에 작게 띄워 주는 위젯입니다.
1분마다 자동으로 갱신되고, 한도가 언제 초기화되는지도 함께 보여 줍니다.

- **무설치 파일 하나로 끝납니다.** Windows 10/11에 기본으로 있는 PowerShell과 WebView2만 사용합니다. 약 0.5MB입니다.
- **API 키가 필요 없습니다.** 위젯 안에서 각 서비스에 평소처럼 로그인하면 됩니다.
- **스마트 앱 컨트롤이 켜진 PC에서도 실행됩니다.** 함께 들어 있는 DLL은 모두 Microsoft가 서명한 공식 WebView2 파일입니다.
- **한국어와 영어를 지원합니다.** Windows 언어를 따라가고, 메뉴에서 직접 고를 수도 있습니다.

> ⚠️ OpenAI, Anthropic 등 각 회사의 공식 프로그램이 아닙니다.
> 각 사이트가 자기 사용량 화면에 쓰는 내부 주소로 사용량을 읽어 오기 때문에, 사이트가 바뀌면 예고 없이 동작하지 않을 수 있습니다.

---

## 지원하는 AI

| 서비스 | 표시 내용 |
|---|---|
| **ChatGPT** | Codex 사용 한도 (5시간 / 주간), 요금제 |
| **Claude** | 5시간 / 주간(전체·Opus·Sonnet) 한도, 요금제 |
| **Cursor** | 이번 결제 주기의 포함 사용량 (예: $12.88 / $20), 추가 사용량 |
| **Perplexity** | Research·Labs 등의 남은 횟수 |
| **Grok** | 남은 질문 수, DeepSearch |

- 처음에는 **ChatGPT와 Claude만** 보입니다. 나머지는 우클릭 → **표시할 AI**에서 체크하면 나타납니다.
- ChatGPT는 일반 채팅 메시지 한도가 아니라 **Codex 사용 한도** 기준입니다. 일반 채팅 한도는 OpenAI가 조회 방법을 제공하지 않습니다.
- **Gemini, GitHub Copilot, Microsoft Copilot**은 웹 로그인으로 사용량을 조회할 방법이 없습니다. 메뉴에 **회색으로 이유와 함께** 표시되고 선택할 수 없습니다.

## 다운로드

[Releases](https://github.com/jbjmanse-hub/ai-usage-widget/releases/latest)에서 둘 중 하나를 받으세요.

| 파일 | 설명 |
|---|---|
| **`AIUsageWidget.cmd`** (추천) | **무설치판.** 더블클릭하면 바로 위젯이 뜹니다. 설치나 바로가기가 없고, 파일을 원하는 곳에 두고 언제든 다시 실행하면 됩니다. |
| `AIUsageWidget-Setup.cmd` | **설치판.** 바탕화면과 시작 메뉴에 **AI Usage Widget** 아이콘을 만들어 줍니다. 설치 후 파일은 지워도 됩니다. |

1. **받은 파일 우클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인**
   인터넷에서 받은 파일에는 Windows가 표시를 남깁니다. 스마트 앱 컨트롤이 켜진 PC에서는 이 단계를 하지 않으면 `.cmd` 파일이 차단됩니다. 코드 서명이 없는 파일이라 Windows가 조심하는 것입니다.
2. 더블클릭합니다. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 화면 오른쪽 위에 위젯이 나타납니다. 각 칸의 **[로그인]** 버튼을 눌러 평소처럼 로그인합니다.

위젯을 숨겨 둔 상태에서 파일을 다시 실행하면 위젯이 다시 화면에 나타납니다.

> 무설치판은 처음 실행할 때 프로그램 파일을 `%LOCALAPPDATA%\AIUsageWidget\app` 에 조용히 풀어 둡니다. Windows는 WebView2 파일을 디스크에서만 불러올 수 있기 때문입니다. 로그인 정보도 같은 폴더에 저장되어 PC에 계속 남습니다.

**업데이트:** 새 버전 파일을 같은 방법으로 차단 해제한 뒤 실행하면 됩니다. 로그인과 설정은 그대로 유지됩니다.

**삭제:** 위젯 우클릭 → **프로그램 삭제…** 를 누르면 프로그램 파일, 바로가기, 저장된 로그인 정보가 모두 지워집니다. 그다음 `.cmd` 파일을 지우세요.

## 로그인과 개인정보

- 비밀번호는 각 서비스의 **실제 로그인 페이지**에 직접 입력합니다. 위젯은 비밀번호를 저장하지도, 어디로 보내지도 않습니다.
- 로그인 쿠키는 이 PC의 `%LOCALAPPDATA%\AIUsageWidget` 에만 저장되며, Chrome이나 Edge와는 분리되어 있습니다.
- 위젯을 껐다 켜도, 재부팅하거나 업데이트해도 로그인이 유지됩니다. 12시간마다 사이트에 접속해 로그인을 연장하고, 그래도 로그아웃되면 트레이 알림이 뜹니다.
- **모든 계정 로그아웃**으로 한 번에 지우거나, **로그아웃 ▸** 에서 서비스별로 지울 수 있습니다.

## 동작 원리

1. 서비스마다 화면에 보이지 않는 브라우저(WebView2)를 하나씩 띄워 두고, 모두 하나의 로컬 프로필을 공유합니다.
2. 시작할 때 각 사이트의 메인 페이지를 한 번 열어 Cloudflare 같은 보안 확인을 통과합니다.
3. 로그인된 사이트 안에서 작은 스크립트를 실행합니다. 스크립트는 사이트의 사용량 화면이 쓰는 것과 같은 내부 주소를 호출합니다.
4. 결과를 막대 그래프와 리셋 시각으로 표시합니다.

실제로 로그아웃된 경우와 보안 확인에 막힌 경우를 구분하고, 보안 확인이면 자동으로 다시 시도합니다.

## AI 서비스 추가 (개발자용)

서비스 하나는 `app/providers/` 의 **`.js` 파일 하나**입니다. 파일 형식과 반환 값은 [영문 README](README.md#adding-an-ai-service-for-developers)와 `app/providers/_template.js` 에 정리되어 있습니다.

- 직접 만든 파일은 `%LOCALAPPDATA%\AIUsageWidget\providers` 에 넣으면 업데이트해도 지워지지 않습니다.
- 넣은 뒤 우클릭 → **표시할 AI → AI 도구 목록 다시 불러오기**를 누르세요.
- 스크립트 안의 `LANG` 값(`'ko'` 또는 `'en'`)으로 항목 이름을 언어별로 바꿀 수 있습니다.

> 이 파일은 로그인된 사이트 안에서 실행되는 코드입니다. 믿을 수 있는 출처의 파일만 넣으세요.

## 직접 빌드하기

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

`app/` 폴더를 `dist/AIUsageWidget.cmd`(무설치판)와 `dist/AIUsageWidget-Setup.cmd`(설치판)로 묶습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "스마트 앱 컨트롤이 … 차단했습니다" | 받은 파일 우클릭 → 속성 → **차단 해제** 체크 → 확인 후 다시 실행 |
| "Windows의 PC 보호" | **추가 정보 → 실행** |
| "로그인이 필요합니다"가 계속 뜸 | 사이트가 로그아웃시킨 것이므로 다시 로그인 |
| "불러오기 실패" 등 오류 | 사이트 방식이 바뀌었을 수 있습니다. `%LOCALAPPDATA%\AIUsageWidget\error.log` 를 확인하고 이슈를 남겨 주세요 |
| 위젯이 사라짐 | 트레이 아이콘을 클릭하면 다시 나타남 |
