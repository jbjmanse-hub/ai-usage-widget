AI 도구 추가 방법
=================

위젯은 AI 도구 하나를 .js 파일 하나로 관리합니다.
기본으로 ChatGPT, Claude가 들어 있고, 파일을 추가하면 다른 도구도 표시할 수 있습니다.


■ 파일 넣는 곳
위젯 우클릭 → [표시할 AI] → [AI 도구 추가하기…] 를 누르면 아래 폴더가 열립니다.

    %LOCALAPPDATA%\AIUsageWidget\providers

여기 넣은 파일은 위젯을 새 버전으로 바꿔도 지워지지 않습니다.
(앱 폴더 안의 providers 폴더는 기본 도구용이라 업데이트 때 덮어써집니다.)


■ 누가 만든 파일을 받았다면
1. 받은 .js 파일을 위 폴더에 넣습니다.
2. 위젯 우클릭 → [표시할 AI] → [AI 도구 목록 다시 불러오기]
3. 새 도구 칸의 [로그인] 버튼으로 로그인합니다.

※ .js 파일은 로그인된 사이트 안에서 실행되는 코드입니다.
  믿을 수 있는 사람에게 받은 파일만 넣으세요.


■ 직접 만들기 (개발 지식 필요)
1. 폴더 안의 _template.js 를 복사하고 이름을 바꿉니다. 예: mytool.js
   (이름이 _ 로 시작하면 무시됩니다)
2. 파일 맨 위의 항목을 고칩니다.
     // @name   위젯에 표시될 이름
     // @host   사용량을 조회할 때 열어둘 주소 (그 사이트의 아무 페이지)
     // @home   사이트 메인 페이지 (선택)
     // @login  로그인 페이지 주소 (선택)
     // @color  제목 색상, 예: #8AB4F8 (선택)
3. 아래 스크립트가 사용량을 가져와서 정해진 모양으로 돌려주게 고칩니다.
   자세한 형식은 _template.js 안의 설명을 보세요.
   - 사이트가 사용량을 어느 주소에서 주는지는 브라우저에서 F12 → Network 탭을 열고
     그 사이트의 사용량 화면을 열었을 때 오가는 요청을 보면 찾을 수 있습니다.
4. 위젯 우클릭 → [표시할 AI] → [AI 도구 목록 다시 불러오기]

파일에 문제가 있으면 위젯에 나타나지 않고
%LOCALAPPDATA%\AIUsageWidget\error.log 에 이유가 기록됩니다.


■ 위젯에 보일 도구 고르기
위젯 우클릭 → [표시할 AI] 에서 체크/해제하면 바로 반영됩니다.
