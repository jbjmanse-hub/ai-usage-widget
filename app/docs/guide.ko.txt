AI 사용량 위젯 사용법
====================

ChatGPT, Claude, Cursor, Perplexity, Grok 구독의 남은 사용량을
바탕화면 구석에 작게 띄워주는 위젯입니다. 1분마다 자동으로 갱신됩니다.


■ 처음 시작
- 각 칸의 [로그인] 버튼을 누르고, 뜨는 창에서 평소처럼 로그인한 뒤
  [로그인 완료]를 누르세요. "불러오는 중…"이 잠깐 표시된 뒤 사용량이 나옵니다.
- 구글 계정 로그인이 막히면 "이메일로 계속하기"로 로그인해 보세요.
- 처음에는 ChatGPT, Claude만 보입니다. 우클릭 → [표시할 AI]에서 다른 AI를 추가하세요.
- 바탕화면이나 시작 메뉴의 "AI Usage Widget" 아이콘으로 실행합니다.


■ 사용
- 오른쪽 위 ⟳ 버튼: 지금 새로고침
- 드래그: 위치 이동 (위치는 기억됩니다)
- 우클릭: 메뉴
- 작업 표시줄 오른쪽 트레이 아이콘: 클릭하면 숨기기/보이기, 우클릭하면 메뉴
- 우클릭 → [언어 (Language)] 에서 한국어/English 전환
- 우클릭 → [Windows 시작 시 자동 실행] 을 켜면 컴퓨터를 켤 때 같이 실행됩니다

색상: 초록(여유) → 노랑(60% 이상 사용) → 빨강(85% 이상 사용)
ChatGPT 칸은 Codex 사용 한도 기준입니다.
(일반 채팅 메시지 한도는 OpenAI가 조회 방법을 제공하지 않습니다.)


■ 지원하는 AI
- 사용량 표시: ChatGPT, Claude, Cursor, Perplexity, Grok
- Gemini, GitHub Copilot, Microsoft Copilot은 사용량을 조회할 방법이 없어서
  메뉴에 회색으로 이유와 함께 표시되며 선택할 수 없습니다.


■ 로그인과 개인정보
- 비밀번호는 각 서비스의 실제 로그인 페이지에 직접 입력되며,
  위젯이 따로 저장하거나 어디로 보내지 않습니다.
- 로그인 정보는 이 PC의 아래 폴더에만 저장됩니다.
    %LOCALAPPDATA%\AIUsageWidget
- 껐다 켜거나 업데이트해도 로그인이 유지되고, 12시간마다 로그인을 연장합니다.
  그래도 사이트가 로그아웃시키면 트레이에 알림이 뜹니다.
- 우클릭 → [모든 계정 로그아웃] 으로 한 번에 지우거나,
  [로그아웃] → 서비스 이름 을 골라 그 서비스만 로그아웃할 수 있습니다.
  다른 사람과 같이 쓰는 PC라면 꼭 로그아웃하세요.


■ 문제가 생기면
- "로그인이 필요합니다"가 계속 뜨면: 사이트가 로그아웃시킨 것입니다. 다시 로그인하세요.
- "불러오기 실패" 등이 뜨면: 사이트 방식이 바뀌었을 수 있습니다.
  %LOCALAPPDATA%\AIUsageWidget\error.log 파일을 만든 사람에게 보내거나 이슈를 남겨 주세요.
  https://github.com/jbjmanse-hub/ai-usage-widget/issues
- 이 프로그램은 OpenAI·Anthropic 등의 공식 프로그램이 아닙니다.


■ 업데이트 / 삭제
- 업데이트: 새 버전의 AIUsageWidget-Setup.cmd 를 실행하면 됩니다. 로그인은 유지됩니다.
- 삭제: 우클릭 → [프로그램 삭제…]. 로그인 정보까지 모두 지워집니다.
