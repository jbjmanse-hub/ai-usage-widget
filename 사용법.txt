AI 사용량 위젯 사용법
====================

ChatGPT, Claude, Cursor, Perplexity, Grok 구독의 남은 사용량을
바탕화면 구석에 작게 띄워주는 프로그램입니다. 1분마다 자동으로 갱신됩니다.
따로 설치할 것은 없습니다. (Windows 10/11 기본 기능만 사용)


■ 처음 실행
1. 받은 zip 파일을 우클릭 → [속성] → 아래쪽 [차단 해제] 체크 → [확인]
   (이걸 먼저 해야 압축을 푼 파일이 막히지 않습니다.)
2. 원하는 곳에 압축을 풉니다. 예: 문서\AI사용량위젯
3. 폴더 안의 "실행.cmd"를 더블클릭합니다.
4. 화면 오른쪽 위에 위젯이 나타납니다.
5. ChatGPT / Claude 칸의 [로그인] 버튼을 누르고,
   뜨는 창에서 평소처럼 로그인한 뒤 [로그인 완료]를 누르세요.
   - 구글 계정 로그인이 막히면 "이메일로 계속하기"로 로그인해 보세요.
   - 로그인을 마치면 그 칸에 "불러오는 중…"이 잠깐 표시된 뒤 사용량이 나옵니다.
   - 안 쓰는 AI는 우클릭 → [표시할 AI]에서 체크를 해제하세요.
6. 우클릭 → [바탕화면에 바로가기 만들기], [Windows 시작 시 자동 실행]을 켜두면 편합니다.


■ 자동 로그인
- 한 번 로그인하면 위젯을 껐다 켜도, 컴퓨터를 재부팅해도 로그인이 유지됩니다.
- 새 버전으로 폴더를 덮어써도 로그인은 그대로입니다.
- 위젯이 12시간마다 사이트에 접속해 로그인을 연장합니다.
- 그래도 사이트가 보안상 로그아웃시키는 경우(비밀번호 변경, 장기간 미사용 등)가 있습니다.
  그때는 트레이에 알림이 뜨니 [로그인] 버튼으로 다시 로그인하면 됩니다.


■ 사용
- 오른쪽 위 ⟳ 버튼: 지금 새로고침
- 드래그: 위치 이동 (위치는 기억됩니다)
- 우클릭: 새로고침, 로그인, 표시할 AI, 항상 위에, 투명도, 자동 실행, 로그아웃, 종료

■ 지원하는 AI
- 사용량 자동 표시: ChatGPT, Claude, Cursor, Perplexity, Grok
- 처음에는 ChatGPT, Claude만 보입니다. 우클릭 → [표시할 AI]에서 쓰는 것을 체크하세요.
- Gemini, GitHub Copilot, Microsoft Copilot은 사용량을 조회할 방법이 없어서
  메뉴에 회색으로 이유와 함께 표시되며 선택할 수 없습니다.
- 다른 AI 도구를 추가하려면 "AI도구_추가방법.txt"를 보세요. (개발 지식 필요)
- 작업 표시줄 오른쪽 트레이 아이콘: 클릭하면 숨기기/보이기, 우클릭하면 같은 메뉴

색상: 초록(여유) → 노랑(60% 이상 사용) → 빨강(85% 이상 사용)
ChatGPT 칸은 Codex 사용 한도 기준입니다.
(일반 채팅 메시지 한도는 OpenAI가 조회 방법을 제공하지 않습니다.)


■ 개인정보
- 비밀번호는 claude.ai / chatgpt.com 로그인 페이지에 직접 입력되며,
  이 프로그램이 따로 저장하거나 어디로 보내지 않습니다.
- 로그인 상태(쿠키)는 이 PC의 아래 폴더에만 저장됩니다.
    %LOCALAPPDATA%\AIUsageWidget
- 우클릭 → [모든 계정 로그아웃] 으로 한 번에 지우거나,
  [로그아웃] → 도구 이름 을 골라 그 도구만 로그아웃할 수 있습니다.
  다른 사람과 같이 쓰는 PC라면 꼭 로그아웃하세요.
- lib 폴더의 파일은 Microsoft가 서명한 공식 WebView2 구성 파일입니다.


■ 문제가 생기면
- 실행.cmd를 눌러도 아무것도 안 뜨면: 1번(차단 해제)을 했는지 확인하세요.
- "불러오기 실패" 등이 뜨면: 사이트 쪽 방식이 바뀌었을 수 있습니다.
  %LOCALAPPDATA%\AIUsageWidget\error.log 파일을 만든 사람에게 보내주세요.
- 이 프로그램은 OpenAI·Anthropic의 공식 프로그램이 아니며,
  사이트 내부 방식을 사용하기 때문에 예고 없이 동작하지 않을 수 있습니다.


■ 완전 삭제 (로그인 정보까지 지우기)
1. 우클릭 → [모든 계정 로그아웃] → [Windows 시작 시 자동 실행] 체크 해제 → [종료]
2. 압축 푼 폴더, 바탕화면 바로가기, %LOCALAPPDATA%\AIUsageWidget 폴더를 삭제
